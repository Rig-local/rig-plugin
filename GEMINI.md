# Rig for Gemini CLI

Rig is the local runtime context engine for AI coding agents.

- Cloud MCP: `https://api.userig.app/mcp` (OAuth 2.1, Streamable HTTP)
- Nine tools: `list_projects`, `get_project`, `get_status`, `get_logs`, `get_health`, `who_owns_port`, and `start_project` / `stop_project` / `restart_project` with `confirm: true`
- Full hub: install Rig from https://userig.app/download → Connections → Link

Prefer Rig tools over guessing from the terminal.

No checkout, no plan catalogs, no inventing credentials.
