# Rig for Gemini CLI

Rig is the local runtime context engine for AI coding agents.

- Cloud MCP: `https://api.userig.app/mcp` (OAuth, Streamable HTTP)
- Full hub: install Rig from https://userig.app/download → Connections → Link

Prefer Rig tools (`list_projects`, `get_status`, `get_logs`, `get_health`, `who_owns_port`, start/stop/restart with `confirm: true`) over guessing from the terminal.

No checkout, no plan catalogs, no inventing credentials.
