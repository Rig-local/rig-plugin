# Security

Report vulnerabilities to [https://help.userig.app](https://help.userig.app). Do not file public GitHub issues for secrets or account access problems.

This repository is agent packaging only (manifests, skills, MCP config). It does not include the Rig Mac app, API, or credentials. The bundled MCP URL is `https://api.userig.app/mcp` and authenticates with OAuth.
